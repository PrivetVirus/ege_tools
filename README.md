# EGE Tools 📚

Набор утилит на **Python** для парсинга и сбора образовательных материалов для подготовки к ЕГЭ. 

**Основной функционал:**
- `ege_parser.py` — автоматический сбор вариантов, задач и ответов с популярных образовательных порталов.
- Удобно для преподавателей и учеников для формирования собственной базы заданий.
