# 📚 EGE Tools (Парсер для ЕГЭ)

**EGE Tools** — это набор Python-инструментов, предназначенных для сбора, фильтрации и автоматизированного анализа образовательных материалов и вариантов для подготовки к ЕГЭ.

---

## 🚀 Особенности
- **🕷️ Эффективный парсинг**: Скрипт `ege_parser.py` автоматически извлекает задания и теорию с популярных образовательных порталов.
- **📑 Структуризация**: Собранные данные удобно форматируются для дальнейшего решения и тестирования.
- **⚡ Автоматизация**: Экономит часы времени на ручной поиск типовых заданий по нужным номерам.
- **💡 Гибкость**: Легко адаптируется под разные предметы.

## 🛠 Технологии
- **Python 3.x**
- **BeautifulSoup4** (или аналоги) — для HTML парсинга
- **requests** — для сетевых запросов

## 📥 Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/PrivetVirus/ege_tools.git
   ```
2. Установите зависимости:
   ```bash
   pip install requests beautifulsoup4
   ```
3. Настройте парсер:
   - Откройте `ege_parser.py` и задайте необходимые параметры (номера заданий, предмет).
4. Запустите парсер:
   ```bash
   python ege_parser.py
   ```

## ⚠️ Дисклеймер
Пожалуйста, не перегружайте сервера образовательных платформ частыми запросами. Используйте `time.sleep()`, чтобы парсер работал этично.
